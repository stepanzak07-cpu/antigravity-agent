# Долговременная память и профиль пользователя (SPIDIKSY)

## 👤 Пользователь
- **Имя / Никнейм:** SPIDIKSY (Степан).
- **Сфера:** Студент ПНИПУ (Механико-технологический факультет).
- **Стиль общения:** Прямой, краткий, без шаблонных приветствий и лишней воды.
- **Язык:** Строго русский язык для всех ответов и пояснений. Код и команды — без перевода.

## 🛠️ Среда агента
- **Окружение:** Linux (Debian/Ubuntu), Python 3.11, bash на сервере Render.
- **Рабочая директория:** `/app/workspace` (или локальная `workspace`).
- **Возможности:**
  - Доступ к консоли Linux (`execute_bash`) — установка библиотек, запуск скриптов, git, curl, проверка кода.
  - Работа с файлами (`read_file`, `write_file`, `list_directory`).
  - Пошаговое выполнение сложных инструкций с отчётом в Telegram.
